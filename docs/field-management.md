# 现场运行与维护入口

2026-10-15 页面方案更新：独立“数据”标签取消，历史图表改由现场控制页传感器卡片和压力/温度仪表上的折线图图标打开；弹窗按日期查看对应传感器，旧私有 `/data` 登录后跳转 `/field`。原始历史和登录保护不变，公开官网不接收这些数据。实际现场安装及服务加载状态须独立核验；下方2026-10-13数据页说明保留为历史记录。

官网顶部的中英文“现场管理 / Field management”链接继续指向既有本地 Tailscale 维护服务。先连接 Tailscale、登录本地账号，再在维护页选择“现场运行”；本地页面路径为 `/field`。原维护设置、照片与录像入口保留。

2026-10-13 新增登录后的“数据”入口 `/data`，英文显示可用 `/data?lang=en`。原官网的每日十分钟图表迁入此页，继续提供日期、测量类别、设备/场地分组、参考上下限及悬停数值。公开导航和公开数据接口同步关闭；浏览器不再向官网索取传感器数据。私有数据来自本地主库只读生成的摘要，不携带任何数据库或上传凭据到客户端。

页面的代码和实时数据服务在私有系统仓库 `services/field-console/` 维护，本公开仓库仅保存入口说明。不把现场控制源码、凭据、原始读数或数据库连接配置放入官网；不通过 Pages Functions/D1 转发实时读数或泵命令。

当前现场页面展示每个测量通道的中文名称、当前或最后一次数值、单位、采样时间与质量/过期状态，每 2 秒刷新展示，不改变传感器采样频率。DO1/DO4 输出状态不等于物理运行反馈。

私有现场程序已按控制器协议接入主泵/回水泵最长 20 秒点动与关闭、全部停止、自动运行启动及“仅重启 ESP32”。点动结束保持停止；自动模式关闭任一泵会同时暂停整套调度并关闭两泵。重启后也保持停止，须单独启动自动运行，控制器检查后等待完整 10 分钟。界面区分命令入队、已接受、等待与输出请求，不把命令回执当成物理运行反馈。

私有鉴权、证书或控制器接口未配置/未启用时操作保持禁用。无自动重发开启或重启指令，断网也不能用网页替代现场急停。控制器固件与本地服务是否启用，应核对现场实际状态，不能用网站发布成功代替；本公开仓库不保存接口实现、设备地址或口令。

修改本地 Python 路由后须另行重载原维护服务。GitHub → Cloudflare Pages 发布只更新公开入口，不会更新本地网页服务或控制器；两类发布分别核验。
